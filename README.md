# ReadyCAD

Параметрическое проектирование корпусной мебели: модель → деталировка → присадка → раскрой →
DXF/PDF → управляющие программы для ЧПУ. Дипломный проект. C++20, CMake, OpenGL 3.3, Dear ImGui.
Интерфейс на турецком языке.

Архитектура описана в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

![ReadyCAD](docs/images/stage5-door-selected.png)

## Что нужно

* CMake ≥ 3.25 и Ninja
* Компилятор с поддержкой C++20: GCC ≥ 11 (MinGW-w64), Clang ≥ 14 или MSVC 2022
* Интернет при первой конфигурации: glm, Catch2, GLFW, ImGui, nlohmann/json,
  nativefiledialog-extended, libHaru и Clipper2 скачиваются через FetchContent в
  `build/<пресет>/_deps` и потом берутся оттуда. У каждого пресета своя копия: зависимости
  debug- и release-сборки компилируются с разными флагами и не должны смешиваться

## Сборка и тесты

```bash
cmake --preset debug
cmake --build --preset debug
ctest --preset debug
```

Приложение: `build/debug/bin/ReadyCAD.exe`. Тесты: `build/debug/bin/readycad_*_tests.exe`.
Тесты можно запускать и напрямую, например `readycad_core_tests.exe "[aabb]"`.

Пресеты:

| Пресет     | Что собирается |
|------------|----------------|
| `debug`    | приложение и тесты, отладка |
| `release`  | приложение и тесты, оптимизация, без консольного окна |
| `headless` | только ядро и тесты, без GUI; предупреждения считаются ошибками (CI) |

На Windows с MinGW `C:\mingw64\bin` должен быть в `PATH` (там лежат gcc и ninja).
Исполняемые файлы линкуются статически, поэтому DLL MinGW рядом с ними не нужны.

## Запуск

```
ReadyCAD.exe [параметры]
  --open <file.rcproj>      открыть проект
  --catalog <0..4>          начать с модели каталога (4 — кухня)
  --holes                   показать отверстия в 3D
  --no-fronts               скрыть фасады
  --select <Kind>[:n]       выделить первую (n-ю) деталь вида (Shelf, Door:2, ...)
  --pdf-dialog              сразу открыть настройки PDF
  --nesting <saw|router>    сразу рассчитать раскрой для пильного центра или ЧПУ
  --count <n>               сколько изделий в раскрое
  --stock                   показать склад листов
  --cut-list                показать таблицу деталей
  --cutting-settings        сразу открыть настройки раскроя
  --export-pdf <file.pdf>   записать PDF-документацию (с раскроем, если он рассчитан) и выйти
  --data-dir <folder>       брать склад и настройки из этой папки (демо, проверки)
  --export-cnc <folder>     записать программы ЧПУ (вместе с --nesting router) и выйти
  --cnc-settings            сразу открыть настройки станка ЧПУ
  --toolpath                показать траекторию в окне раскроя
  --screenshot <file.bmp>   сохранить окно в картинку и выйти
  --package <folder>        без окна: рассчитать раскрой, записать пакет для цеха в эту
                            (новую или пустую) папку, напечатать сводку и выйти
```

Пакет для цеха без окна: проект в двух экземплярах, раскрой на ЧПУ, всё в одну папку
(PDF, DXF деталей и листов, программы ЧПУ, CSV для пилы, сводка `OZET.txt`):
`ReadyCAD.exe --open proje.rcproj --count 2 --nesting router --package proje_URETIM`.
Код выхода 0 — готово, 1 — ошибка (причина в выводе ошибок). Release-сборка — оконная
программа, и оболочка её не ждёт. В скриптах PowerShell направьте вывод в конвейер:
`ReadyCAD.exe ... | Out-Host` — тогда оболочка дождётся конца, а `$LASTEXITCODE` будет верным.

Горячие клавиши: Ctrl+Z / Ctrl+Y — отмена и повтор, Ctrl+S — сохранить, Ctrl+O — открыть,
Ctrl+P — документация в PDF, Ctrl+E — пакет для цеха, F5 — рассчитать раскрой, Delete —
удалить выбранную полку, дверь или блок ящиков.

Меню «Dışa aktar»: «Üretim paketi» — всё для цеха в одной новой папке (если раскрой не
рассчитан, он считается сначала); PDF-документация (деталировка, фурнитура, раскрой, сборочный
чертёж, чертежи деталей); спецификация в CSV для оптимизатора пилы или Excel; все детали в одном
DXF или каждая деталь в своём DXF для CAD/CAM; раскладка каждого листа в своём DXF.

Кухня: «Mutfak (düz)» в каталоге — нижние модули на цоколе, столешница с вырезами под мойку
и варочную панель, навесные шкафы. В «Parametreler» — размеры кухни и «Dolap ekle», у
выбранного модуля — верх (крышка или кушаки), цоколь, ширина, вырез в столешнице, перестановка
и удаление. Вырезы попадают в чертежи (слой `CUTOUT`) и, если столешница в раскрое, в
программы ЧПУ.

![Кухня](docs/images/kitchen-editor.png)

Колонка «Kesim» в таблице деталей (и флажок в свойствах детали) выводит деталь из раскроя:
например, задняя стенка заказывается уже нарезанной. Деталь остаётся в спецификации и
документах.

Меню «Kesim» и окно «Kesim planı»: раскрой на пильном центре или нестинг на ЧПУ, прогресс
генетического алгоритма, карта каждого листа, траектория фрезы, списание листов со склада.
Окно «Levha stoku» — склад листов и деловых остатков. «Kesim → CNC ayarları...» — инструменты
и диалект G-code нестинг-центра; «Dışa aktar → CNC programları...» — по программе на лист.

![Раскрой на пильном центре](docs/images/stage7-saw.png)

Склад и настройки раскроя принадлежат мастерской, а не проекту. Они лежат в папке
пользователя и общие для всех проектов: на Windows `%APPDATA%\ReadyCAD\stock.rcstock` и
`settings.json`, в Linux `~/.config/ReadyCAD`.

Тест `gui_smoke_screenshot` (метка `gui`) запускает настоящее окно. На машине без OpenGL 3.3
его можно пропустить: `ctest --preset debug -LE gui`.

Сквозные тесты этапа 9: путь пользователя от каталога до файлов, каждая модель на обоих станках,
случайные правки, путь кухни (`tests/integration`), а также настоящий `ReadyCAD.exe` в пакетном режиме
(метка `batch`). Длинный прогон случайных правок скрыт:
`readycad_integration_tests.exe "[soak]"`.
